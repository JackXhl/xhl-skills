# 表达、情感、语法

口气像刚用完来转述。有一点「我发现了」。读者是要去用产品的人。

## 表达

短句为主。问句可以开场，全篇问句不超过 3 个。

先写谁做了什么，再写结果。按钮名、清晰度、MB 用当前图上的原文。

人味来自具体动作，不来自口头禅。不要为了像人而加「老铁」「咱就是说」「泡杯茶」。

说明书腔的典型形状，见了就改：

| 说明书 | 安利 |
|--------|------|
| 本产品支持多平台解析 | 抖音、B 站这些常用的，首页都能贴 |
| 实现了批量处理能力 | 好几条就走批量 |
| 提供文案提取功能 | 标题、口播也能一起拿走 |
| 用户可通过浏览器访问 | 打开一个网页就行 |

同一观点不要换说法写第二遍。后一段必须新增动作、数字、入口或边界。

## 情感

痛点落到手上的动作：翻来翻去找不到保存、下下来不对劲、还要再换一个工具。不要「痛点深深」「很麻烦」。

升温靠叠加烦，不靠喊。装软件、换工具、文案还要另拷，三件叠在开场就够。

信任靠边界：只支持公开内容、画面里的字去不掉、版权归原作者。边界写清楚，读者才敢信亮点。

结尾是鼓励，不是命令，也不是暗示他自己会收藏。

- 好：值得先收藏这个站 + 网址 + 今天先试一条
- 好：赶紧打开 {域名}，收藏起来不迷路
- 坏：绝对值得收藏、马上购买、错过就没了
- 坏：顺了，你自己会收藏（太软，人不知道去哪）

不要点名贬竞品。不要段段「价值在于」。不要装义愤。

## 语法与句式

- 2～5 行一段。单句成段只留给「别急」这种需要停的地方。长文种草里通常不需要。
- 全篇加粗 3～8 处。列表项可以加粗关键词，不要整段加粗。
- 不用破折号 `—` `——` `–`。
- 提示性冒号少用。「一句话总结：」「核心是：」改成句号或逗号。网址、代码除外。
- 不写翻案腔：不是……而是、并非……而是、不在于……而在于、与其说……不如说、你以为……其实。判断从正面下。
- 「不只……还……」可以，那是递进。
- 三项以上同构排比不要。两项就停，第三项换说法。
- 动词不要名词化。「完成了对流程的优化」→「这几步放在同一个网页里」。
- 不用「说白了」「说穿了」「先说结论」「值得注意的是」「从某种意义上说」。

## 可复用槽位（填自己的事实，禁止填回范文故事）

- 你是不是也遇到过：{具体卡住的动作}。
- 更麻烦的是，有时你要的不只是{A}。{B}也想一并拿走。
- 网上同类{品类}不少，真正{产品能兑现的差}的，没那么好找。
- 今天给大家安利一个我最近在用的，**{产品名}**。
- 适合这几类人：{身份}。
- 我按{当前图上的平台}试了一条：{动作}，结果是{图上能看见的}。
- 今天先试一条{对象}，走完「{步骤}」。顺的话再试{进阶}。

## 规格、边界怎么说

情绪接具体卡住的动作。规格只写当前图上有的档，不要默认「最高那档一定有」。

平台、次数、价格只写事实卡或当前页能数出来的。不要抄范文的 100+、无水印，除非事实卡允许。
