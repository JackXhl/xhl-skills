# 对照

下面是成稿里抽出来的句子，不是完整文章。

## 要这样写

开场只分人，不铺痛点。

> 最近总有人问，有没有能先白嫖、或者学生价特别便宜的云服务器。我把现在还能领的几条整理了一下。小白练手、学生党、自己开游戏服，分开看就行。

一家一段，图贴在刚说的那句下面，链接嵌进句子。

> 轻量应用服务器是 **2核2G 3M，免费一个月**。普通搭个博客、跑跑测试、挂个小站，这个配置够用。
>
> （体验馆截图，能看清 2核2G3M、试用一个月）
>
> 试用走 [腾讯云免费试用](https://example.com/trial)

结尾只说谁选谁。

> 想短期先试试，选腾讯云那一个月。学生党把校园机和阿里云那张券都看看。开游戏服直接雨云。

## 不要这样写

- 八节说明书：适合人群、功能亮点、使用场景、小编总结再把链接列一遍。
- 开场「你是不是也遇到过。想弄一台服务器练练手……」
- 链接独占一行，前面写「试用入口：」
- 电报口气：更香、叠不上、先摸熟、白嫖一个月就完事。
- 结尾「今天把资格领上就行，机器回头再开」。
- 教人怎么进控制台、怎么 SSH、怎么备案。
- 两张图连在一起，上面那句没写到图里的字。
- 文案写泰拉瑞亚，截图里只有 Minecraft、帕鲁、饥荒。
- 用发白的手机首页冒充「一分钟开 MC 服」。
