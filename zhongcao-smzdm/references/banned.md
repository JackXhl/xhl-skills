# 禁止项

只学范文结构，不学范文故事和承诺。

## 从范文带走会翻车的（任何产品都禁）

- 产品名：i导航解析器、idaohang123、idaohang
- 范文卖点原句：无水印、100+ 平台、扒主页下视频——除非**当前**事实卡明确允许
- 用途：二创素材、拆竞品账号、整理一个号的所有内容——除非事实卡允许
- 套话：绝对值得收藏、真正全面、写得热闹用起来别扭
- 排比超过三连、每小节「价值在于……」

## 制作痕迹（任何产品都禁）

打了码、打码、马赛克、糊掉、图上看不清、这张图、图上这条、我把标题遮了。

标题、账号被遮，就当没这回事，直接写功能和结果。

## 产品兑现不了就不要写

以当篇事实卡为准。事实卡没有的能力，默认当不能说。

写视频保存类工具时，常见翻车（没写进事实卡就当禁止）：

- 去掉创作者烧进画面的水印
- 100+ 平台
- 把某个号下面的内容一次存完
- 私密 / 已删除 / 审核中 / 付费也能下
- 编造每日免费次数和会员价格
- 默认总有某一档最高清晰度
- 把「只出字」的入口写成批量下视频

## 句式禁止

不是……而是 / 并非……而是 / 不在于……而在于 / 与其说……不如说 / 你以为……其实

破折号。提示性冒号（「核心是：」「一句话总结：」）。

## 借口对照

| 借口 | 事实 |
|------|------|
| 太像介绍是因为功能要讲清楚 | 功能放在 8 节里讲。开场只给人一个卡住的动作 |
| 规格以前官网有过 | 以当前图为准。图上没有就删 |
| 打码要说明一下比较诚实 | 那是制作痕迹。读者不是来审图的 |
| 拆掉 8 节更有人味 | 人味在口气，骨架不动 |
| 范文那句读者爱搜 | 当前产品兑现不了。搜来的人会觉得被骗 |
| 把能力写炸更吸引人 | 写炸就是写错。预期检查会拦住 |
| 先交一版再对图 | 对不上的数字会进成品。先对图 |
| 老铁、口语词更能像人 | 像人靠动作和取舍，不靠称呼 |
