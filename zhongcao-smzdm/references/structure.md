# 种草长文结构

营销种草长文的通用骨架只有一条链：

**卡住 → 更烦 → 原来有个办法 → 适合谁 → 我试给你看 → 进阶 → 你怎么开始 → 收藏再走**

什么值得买社区安利体，是这条链的 8 节展开。不要发明第四种「更有创意」的目录。

## 通用链（任何产品）

| 拍 | 读者心里的问题 | 这一拍要交出的东西 |
|----|----------------|--------------------|
| 痛点 | 这说的是我吗 | 一个具体卡住的动作，不要形容词 |
| 升级 | 就这点麻烦？ | 叠加第二、第三个烦（换工具、装软件、还要文案） |
| 垫一句 | 网上不是很多吗 | 承认同类多，但不点名踩。落到「打开就能用」这种差 |
| 引出 | 到底是啥 | 产品名、入口、一张首屏真图 |
| 适合谁 | 我算不算 | 清单。不适合的也写，建立可信 |
| 实测 | 真的能用？ | 每节一个动作 + 一张当前图上的结果 |
| 进阶 | 多了怎么办 | 批量、文案等，以图和官网为准 |
| 步骤 | 我现在做什么 | 三步，对准真实入口，不要另编 |
| 收束 | 我收藏啥 | 3 个能兑现的点 + 网址 + 先试一条 |

## 交稿目录（8 节，可砍成 5）

开场在一级标题下，不要做成第 0 节。

```
# {标题}

{痛点一段}
{升级一段}
{市场垫一句}
今天给大家安利……**产品名**
网站在 {url}
{首屏怎么用，一句话}
![](首屏图)

## 1. 适合人群
## 2. 功能亮点
## 3. 高频使用场景
### 3.1 {当前图上的平台}……
### 3.2 ……
### 3.3 ……
## 4. {进阶 A}
## 5. {进阶 B}
## 6. 它把这几步放在同一个网页里
## 7. 新手推荐使用步骤
## 8. 总结
```

砍 5 节时保留：适合人群、功能亮点、一个实测、新手步骤、总结。开场三拍仍在。

## 开场三拍（不能删）

痛点要落到动作：刷到、找不到保存、想拷标题还得换工具。不要「在这个信息过载的时代」。

升级用递进，不用翻案。「有时你要的不只是下一条」可以；「它解决的不是 A，而是 B」不行。

市场垫一句就够。不要段段升维「真正全面的很少」。

引出之后马上给入口和首屏图。读者此时已经愿意往下看，不要再解释品牌理念。

## 各节写什么

**1 适合人群**：先一句它偏什么（实用 / 网页即用），再 4～6 条身份。最后「属于上面任何一种，可以接着看」。不适合谁写在亮点节末或单独两句：私密、扒号、商用二发。

**2 功能亮点**：只写此刻能兑现的。每条能指向官网或当前图。节末写边界：公开内容、去不掉画面里的字、版权归原作者。

**3 高频场景**：场景必须能对上当前截图。图上是哪个平台就写哪个。不要凭记忆写上一轮的规格。没图的入口只说「步骤一样」，不要假装实测。

**4 / 5 进阶**：图上有就写，没有就不要用旧版记忆补。批量是多条链接，不是扒某个号。文案入口有几块写几块，别走错。

**6 收链**：5 步以内。找到 → 贴上 → 预览 → 保存 → 需要字再提取。不要再展开成新教程。

**7 新手步骤**：对准真实入口顺序。先单条，再批量，最后文案。每步一个动作。

**8 总结**：3～5 条能兑现的优点 + 网址 +「今天先试一条」。鼓励收藏，不喊下单。可放「赶紧打开 {域名}，收藏起来不迷路」这种引导，不要「绝对值得收藏」。

## 段落与配图

- 2～5 行一段。列表可以密。
- 加粗全篇 3～8 处关键词，不要行行加粗。
- 每节一张官网真图。图注写动作，不写「如图所示」。
- 正文禁止写：打了码、打码、马赛克、糊掉、图上看不清、这张图、图上这条。标题被遮了就当没这回事。

## 和范文的诚实差异

范文可以走「功能越多越好」。产品承诺更窄时，仿写成功 = 读者觉得这是同一类实测安利文，但不会以为产品能去水印、扒主页、覆盖 100+ 平台。
