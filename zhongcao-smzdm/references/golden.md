# 成稿样例拆解

这是一份打磨过的什么值得买安利体样例。换产品时只学判断，不复述产品名和句子。

对照稿（本仓库有则打开）：`youjian-image/打开网页就能存公开视频.md`

## 标题

`免费公开视频保存神器，连文案都能提取`

占了范文槽位，但对象是「公开视频保存」，不是「抖音无水印下载」。附加能力「文案」是产品真有的。

## 开场

1. 卡住：平台里没有保存入口，拷标题还要换工具。
2. 升级：好几条、文案、不想装软件，三件叠上。
3. 垫一句：同类不少，打开就能用、公开能存、文案能拷的不好找。
4. 引出柚见下载 + 网址 + 输入框和一键提取 + 首屏图。

没有第一句报功能，没有「在这个时代」。

## 对图

B 站实测写 720P / 360P、242 MB / 89 MB，来自当时的 `解析结果页2.png`。没有沿用记忆里的 1080P。

批量节写明「多条链接排队处理。某个号下面的视频要一次存完，这个站现在没有这个入口。」预期被按住。

文案节把图文 / 视频 / 作者主页三块入口拆开，避免读者走错。作者主页写「现在只出字」。

## 结尾

优点都是能兑现的短句。网址在。动作是「今天就可以先试一条……走完提取 → 预览 → 下载」。

没有「绝对值得收藏」，也没有把收藏推给读者自己去想。

## 这篇改过的错（不要改回去）

- 写成规格说明书，没有人味 → 开场改回动作。
- 正文 1080P，图上只有 720P / 360P → 整段按图重写。
- 写「标题打了码」 → 删制作痕迹。
- 拆掉 8 节改短评 → 骨架加回去，口气留着。
