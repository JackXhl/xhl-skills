# 云服务器推广图文

读者是来挑能领的机器，不是来看说明书。学的是厂商优惠帖的分段和口气：一家一段，先讲配置和适合谁，再给入口，图贴在对应那句话后面。

不要套 `zhongcao-smzdm` 的 8 节骨架，也不要写成操作教程。

成稿对照：[examples.md](examples.md)

## 写之前

1. 事实以**这一次打开的页面**为准。用户口述和页面不一致时，正文跟页面走，并写明「下单以登录后为准」。
2. 推广链接原样保留，一个不改。链接文字用中文，正文里不出现裸 URL。
3. 先截图再写对应段落。旧图发白、手机宽度、字看不清，整张作废。

## 文章骨架

标题用用户给的。用户没给，就用「还在找……」这种能搜到的问句，不要「神器 / 第一 / 闭眼入」。

开场两句就够。有人在问什么，这篇分成哪几类人看。不要「你是不是也遇到过」，不要痛点三段论。

然后按厂商分节，用 `## 一、` `## 二、`。一节里可以有试用和学生两条，各自成段。

每一段只干四件事，顺序固定：

1. 给谁用（新用户、学生、开 MC / 帕鲁）
2. 配置和价格，关键数字加粗
3. 一句够用或边界（额度用完会扣费、不能和折扣叠加、限购一台）
4. 紧跟一张对得上的截图，再跟入口

入口嵌进句子，不要单独一行「试用入口：」。

```markdown
试用走 [腾讯云免费试用](https://example.com/trial)
```

结尾只回答「谁选哪家」，两三句，各家不再重复贴链接。不要催领，不要「先把资格领上，机器回头再开」，不要文末链接汇总。

## 口气

完整句子，像优惠帖，不像电报，也不像客服。

用：比较适合、这个配置够用、限购一台、单机练手挺合适、下单以登录后为准。

不用：更香、叠不上、先摸熟、闭眼冲、建议大家、综上所述。

不写控制台、SSH、备案、重装系统的步骤。边界用一句带过（额度用完会扣费，不用了关掉）。

中文冒号只出现在引号里的页面原文。不要破折号，不要「不是 A，而是 B」的翻案句。句子长短要错开。

交稿前跑同仓库 `style-imitate-human-writer` 的检查脚本：

```bash
python ../style-imitate-human-writer/assets/check_prose.py 稿件.md
```

翻案句、黑话、硬停词必须是 0。句子长度过于接近只是提醒，改到长短错开即可。

## 图文

一句事实，一张图，图在这句话下面。不要两张图中间没有字，也不要一段里堆完所有优惠再补图。

图里必须能读出正文刚说的那几个字（配置、价格、折扣、游戏名）。裁切里没有的名字不要写。游戏名被裁出画面，就改文案，不改口说「也在同一排」。

截图要求：

- 桌面宽度，约 1440。手机宽度的雨云首页会发白，字叠在浅底上，不能用。
- 等背景图加载完再截。头图是浅色字时，确认背后是深色画面，不是一片白。
- 浮动的文档、分享、拼团按钮挡住正文就先隐藏再截。
- 轮播停在正文要的那一帧（雨云要「一分钟开好 MC 服」那帧，不是社区或建站）。
- 游戏模板往往要点进面板（雨云选 RGP）才会出现。默认 VPS 页没有帕鲁、饥荒。
- 折扣文案在下单区（「新用户可领首月5折券」「年付7折」），不要用发灰的旧活动图顶上。
- 保存到文章同级的图片目录，文件名按出现顺序编号。换图后，对应段落按新图重写。

## 常见页面事实

写进正文前仍要打开页面核对，下面只是容易写错的地方：

- 腾讯云轻量试用是新用户一个月，不是长期免费。
- 云+校园页面常标折扣（如一年 1.3 折），三个月 30 元、一年 112 元这类金额要写「常见价」或「登录后为准」，不要写成页面上已经印着。
- 阿里云个人试用的 300 元是额度，用完会扣费，不是三个月随便用。
- 学生 300 元券一年有效，不和新用户折扣叠加。
- 雨云游戏云约 25 元/月起。新用户首月 5 折、三月 9 折、半年 8 折、年付 7 折。1 元可试，七天可退。人数档以当前下单页标注为准，用户给的对照表只作补充，和页面冲突时跟页面。

- [ ] 没有发白图、没有操作步骤、没有催领、没有文末链接堆
