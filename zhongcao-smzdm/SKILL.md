# 什么值得买式种草长文

读者打开是来找能用的工具，不是来审规格书。学的是范文的**结构与口气**，不学范文的产品承诺。

本技能与具体产品解耦。换产品只换事实卡和当前截图，8 节骨架、五项检验、标题槽位不变。

种子范文：[免费抖音视频下载神器，连文案都能提取](https://post.smzdm.com/p/anvp2rq7/)  
结构拆解：[references/golden.md](references/golden.md)

```
- [ ] 0 对材料（有图先对图；无事实卡先停）
- [ ] 1 定标题（出 3 个，用户未指定就自选 1 个）
- [ ] 2 按 8 节骨架写，开场 3 段不能删
- [ ] 3 词汇检查
- [ ] 4 表达检查
- [ ] 5 预期检查
- [ ] 6 情感检查
- [ ] 7 结构 / 语法检查
- [ ] 8 python scripts/check.py <稿件.md> 退出码 0 才能交
```

未勾完不准说写完了。检查过程不要交给用户。用户只要文章，就只交文章。

## 输入前提

开始前必须有：

1. **事实卡**：能说 / 不能说 / 边界（价格、次数、平台数、水印、批量含义）。用户没给，就先问，不准用范文或记忆顶上。
2. **当前截图或可核验的官网页**。有图先对图。无图不准写具体清晰度、次数、价格、平台总数。

某个仓库若自带该产品的事实卡，用仓库里的。没有就向用户要，不要用范文或记忆顶上。

## 何时不用

- 小红书图文、封面卡、叠字笔记（另一套卡片技能）
- 口播、介绍视频、字幕稿
- 纯说明书、帮助中心、更新日志
- 用户明确只要短评 / 朋友圈 / 海报文案

## 0. 写前对材料（硬停止）

用户给了截图，先打开**这一次**每一张，列内部清单再动笔。上一轮对话的旧图作废。

清单至少：文件名、哪一页、输入框或关键文案、按钮原文、分栏数字、规格标签、文件大小。

正文里的按钮名、规格、数字，必须能在某一张**当前图**上指出来。指不出来就删。图换了，相关段落整段重写。

详：[references/structure.md](references/structure.md)

## 1. 标题

槽位：`{免费/省事}{对象}{品类}神器，连{附加能力}都能{动词}`

每次出 3 个，勿堆。标题要能搜到事实卡里**能兑现**的词。

不要用事实卡禁止的词，也不要用：第一、唯一、绝对值得收藏。

详：[references/title.md](references/title.md)

## 2. 写作

开场固定三拍，然后 8 节目录。人味在口气，不在拆骨架。

1. 痛点（具体卡住的动作）
2. 痛点升级（第二、第三件烦）
3. 市场垫一句（不点名贬竞品）
4. 引出产品 + 入口 + 首屏图
5. `## 1. 适合人群`
6. `## 2. 功能亮点`
7. `## 3. 高频使用场景`（3.1 / 3.2 / 3.3，有图才写实测）
8. `## 4.` 进阶能力 A（事实卡里的第二能力）
9. `## 5.` 进阶能力 B（事实卡里的第三能力）
10. `## 6.` 把步骤收成一条链
11. `## 7. 新手推荐使用步骤`
12. `## 8. 总结` + 网址 + 先试一下

可砍成 5 节：适合人群、亮点、一个实测场景、步骤、总结。目录编号仍要在。不要改成随笔。

每节一个动作，配一张真图。事实卡没有的能力，不要写成有。

详：[references/structure.md](references/structure.md)、[references/voice.md](references/voice.md)

## 3–7. 五项检验

初稿写完再读 [references/checks.md](references/checks.md)。五项都过，再跑脚本。

| 关 | 问的是 | 不过就 |
|----|--------|--------|
| 词汇 | 有没有擦边词、范文词、说明书词 | 换能兑现的词，删堆砌 |
| 表达 | 还像不像介绍 / 规格书 | 改成刚用完来转述 |
| 预期 | 读者会不会以为产品有事实卡没有的能力 | 把承诺降到能兑现的 |
| 情感 | 痛点虚不虚，结尾软不软、凶不凶 | 动作要具体，结尾鼓励收藏 |
| 结构语法 | 8 节还在不在，句子顺不顺 | 补节，拆长句，清翻案腔 |

禁止项总表：[references/banned.md](references/banned.md)

## 8. 脚本

在技能目录下：

```bash
python scripts/check.py <稿件.md>
```

硬伤退出码 1，警告印在 stderr。警告涉及当前截图或事实卡的，必须人工核对后再交。

## 红旗 — 停下来重写

- 开头第一句就报功能
- 凭记忆写了规格、次数、价格、平台总数
- 正文出现打码、马赛克、这张图、图上看不清
- 把 8 节改成短评，说这样更有人味
- 抄了范文的产品名或范文的兑现不了的卖点
- 为了人味加「老铁」「咱就是说」
- 检查清单还没勾完就交稿
